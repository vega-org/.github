### What Vega is

Vega is a **neutral, general-purpose media player and casting app**.
Vega provides:
- A media player for local and network playback
- Casting to supported devices (e.g., Chromecast/DLNA)
- An **environment that runs user-generated scripts**, which users install and manage themselves

### No hosted content

Vega and the **vega-org** organization **do not host, store, upload, distribute, index or link to** any media content. Vega does not make any content available on its own. Everything played in Vega comes from sources that the user picks and adds.

### Third-party providers and plugins
